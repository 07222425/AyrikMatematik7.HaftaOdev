# Ayrık Matematik 7.Hafta Ödev

Alıştırmalarda bir yapının neden grup olmadığını göstermek ve mod 5 ile mod 7 tablolarını oluşturmak üzerinde durdum. Hata ya da eksik görürseniz issue açmaktan çekinmeyin.
